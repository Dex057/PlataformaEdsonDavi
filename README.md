# PlataformaEdsonDavi

Jogo de plataforma em Unity (URP).

- Branch `main`: Unity **6000.6.9f1** (versao principal).
- Branch `unity-6000.3`: mesma fase e scripts, com pacotes ajustados para o Unity **6000.3.22f1**. Ainda nao foi aberta no editor 6.3. Se o Package Manager reclamar de algum pacote, o ajuste e so no `Packages/manifest.json`.

Ao abrir pela primeira vez o Unity recria a pasta `Library` (demora).
